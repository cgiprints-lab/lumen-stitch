# Lumen Photo Suite (Longshot mod)

Ansel-style photo capabilities for Longshot, as a plain manifest mod: free
camera, world freeze, HUD-free framing, and capture jobs (single / stereo /
gigapixel grid / 360 cube) that produce Lumen job manifests the Lumen
stitcher turns into gigapixel BigTIFFs, panoramas and side-by-side stereo.

Controls: **L3+R3** (or F8) photo mode; right stick/mouse look, left stick
fly, ZL/ZR up-down; **R** or **F5** cycles the job (in photo mode: D-pad ◀ ▶);
**ZR**/**F6** or **A** shoots; **B** cancels. All remappable in the Mods
tab's settings for this mod.

Capture (pixel readback) needs the capture seam proposed upstream
(../seams.md) - until it lands, the mod runs photo mode fully and logs each
job's plan instead of writing tiles. See the adapter README
(../README.md) for install and stitching.
